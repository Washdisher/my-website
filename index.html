A brief introduction

I'm an AML analyst at Protiviti in Boston, where I conduct financial crimes investigations, draft Suspicious Transaction Reports to FINTRAC, and build audit-ready case files for Canadian retail banking clients.

03 — Projects

What I've built

Independent project

SENTINEL

A free, browser-based AML training simulation

You play a new transaction-monitoring analyst working alert cases and stamping each one No Further Action or File SAR.

Training Mode is the default. Analyst Mode adds SAR narratives, scored on who, what, when, how, and why. Built for AML analysts, BSA officers, and bank training programs.

  • 45 cases
  • 17 typologies
  • 3 in-game weeks
Structuring TBML OFAC 50% Rule Pig-butchering Labor trafficking NPO/terrorist financing

Guided walkthrough on first run · No login · Progress saved in your browser · Desktop and mobile · Built with React as a single self‑contained file
